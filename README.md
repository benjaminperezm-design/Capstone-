# Recicaps | Proyecto Capstone

> Sistema de monitoreo, medición y registro de residuos reciclables para el Hub Providencia.

## Propósito

Recicaps busca comprender y mejorar la gestión de residuos reciclables del Hub Providencia. El proyecto propone levantar información confiable sobre los residuos generados y utilizarla para apoyar decisiones, mejorar la clasificación y fomentar prácticas sostenibles.
