# Semana 3 | Mapas conceptual y de empatía

## Mapa conceptual

El mapa conceptual identifica el desafío central: monitorear, medir y registrar los residuos reciclables del Hub Providencia para lograr una gestión más eficiente y sostenible.

Incluye los siguientes elementos:

- **Contexto:** Hub Providencia, generación cotidiana de residuos y puntos de reciclaje existentes.
- **Actores:** usuarios, trabajadores, personal de aseo, administración, equipo de sostenibilidad y gestores de residuos.
- **Causas o factores por investigar:** falta de registro, seguimiento, información, clasificación, conciencia ambiental o infraestructura adecuada.
- **Consecuencias:** dificultad para medir el impacto, gestión poco eficiente, menor reciclaje, impacto ambiental y desmotivación.
- **Conceptos clave:** reciclaje, sostenibilidad, monitoreo, medición, registro de datos y gestión de residuos.
- **Lo que sabemos:** existe el desafío, se generan residuos reciclables y se requiere mejorar la gestión.
- **Lo que aún necesitamos saber:** cantidades y tipos de residuos, proceso actual, dificultades de los usuarios, sistema de registro, porcentaje realmente reciclado, responsables y uso de los puntos.

## Mapa de empatía

**Usuario/actor principal: encargado o encargada de gestión de residuos del Hub Providencia.**

| Dimensión | Hallazgos iniciales |
| --- | --- |
| **Piensa y siente** | Le preocupa que los residuos no se separen ni registren correctamente; necesita datos claros, busca una solución simple y confiable. |
| **Ve** | Contenedores con uso irregular, residuos mal clasificados, registros dispersos y oportunidades de mejora mediante tecnología. |
| **Oye** | “Falta tiempo y personal para revisar todo”, “No sabemos cuánto se recicla realmente” y “Necesitamos reportes claros”. |
| **Dice y hace** | Revisa puntos de reciclaje, coordina retiros, consulta indicadores y busca herramientas para monitorear la información. |
| **Esfuerzos (dolores)** | Medir manualmente consume tiempo y genera errores; cuesta detectar hábitos, comparar resultados y coordinar actores. |
| **Resultados esperados** | Datos ordenados y confiables, mejores decisiones, mayor eficiencia, menos errores de clasificación e impacto sostenible demostrable. |

### Supuestos a validar con usuarios

1. El proceso manual actual les toma demasiado tiempo y no entrega datos confiables.
2. Los usuarios necesitan señalización o guía más clara para clasificar los residuos.
3. Los encargados usarían un sistema sencillo de registro si reduce trabajo y permite obtener reportes.
